## 原 ETF 存档的一致性核对

使用本机保留的原研究 JSON 存档，仅只读载入，不把行情或旧报告复制进公开仓库。脚本验证外层规范 JSON 哈希，通过哈希关联价格、调仓计划、目标权重、账本及绩效记录，再用新入口重新计算。

| 核对项 | 结果 |
| --- | --- |
| 价格矩阵 | 1,947 个交易日 × 11 ETF |
| 样本 | 2019-01-02 至 2026-09-30 |
| 月度调仓 | 每策略 69 次 |
| 日度账本 | 每策略 1,442 行 |
| 策略 | 等权、样本最小方差、常相关收缩最小方差 |
| 分期绩效 | 9 组 |
| 数值差异 | 所比较数值的最大绝对差为 0 |

上述核对使用 NumPy 2.5.3 的原计算环境。时间戳、适配后的实现指纹和新输入身份不是旧存档身份，不能据此宣称新报告具有原报告的同一 SHA。核对的是决策、权重、记账与指标数值。

保有原研究存档的用户可运行：

```console
python scripts/verify_local_etf_parity.py --archive-dir PATH_TO_PRIVATE_ETF_REPORTS --output outputs/parity.json
```

普通 GitHub 克隆不包含这些私有存档，因此该命令不是公开 CI 的前置条件。默认期望 69 次事件；多个存档时需显式选择账本哈希。缺少存档、内容哈希损坏或结果不一致会报错。

## 未由这些检查证明的事项

计算一致性不代表数据商的复权、公司行动、历史信息可得性已被独立认证，也不证明因子有预测能力。固定样本仍有选择与幸存者偏差。没有进行新的统计显著性验证，也没有把已观察的历史区间重新认证为未见测试集。小时级、AI 新闻处理及实盘交易均不在当前实现范围。
