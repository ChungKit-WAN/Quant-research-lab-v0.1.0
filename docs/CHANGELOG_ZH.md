# Changelog

## 0.11.0 — 2026-10-21 / v0.11 本地升级

- 新增 `refresh` 一键下载、原始／计算数据库、交易日核验、动态日期窗口、ETF 与个股回测、全部研究报告。
- 新增中英文总览及 11 行业各自的中英文页面；默认 55 只可编辑样本股。展示全部 100 指标，65 项计算、35 项等待时点财务数据；支持指标升降序和 CSV 导出。
- 预先保存 9 组成本、持股数、排名窗口与因子组评分移除实验计划，保存全部结果与失败记录，自动输出中英文敏感性报告。
- 全部已计算绩效和逐资产实际权重统计在回测报告中展示并可排序。
- Windows 启动器自动校验下载、安装独立 Python，按机器和路径建立环境。支持中文目录，保留 TLS 证书验证；macOS/Linux 脚本待实机验证。
- 完整月份判断以纽约收盘为准；运行失败不提升为最新成功报告。原始来源、配置、实验计划与输出哈希均留存。

本次按用户名称使用 v0.11；先前建议的 v0.1.1 研究验证范围合并于本版。本次源码尚未推送 GitHub。财务因子、完整历史成分股及独立数据认证仍未完成。
